dp[i]表示以nums[i]结尾的最长递增子序列长度
那么我们维护这个dp
当val>dp[j] (j<i)时
说明可以追加元素,这时维护Max

```python
class Solution:

    def lengthOfLIS(self, nums: List[int]) -> int:

        dp=[1]*len(nums)

        ans=1

        for i in range(0,len(nums)):

            for j in range(i):

                if nums[i]>nums[j]:

                    dp[i]=max(dp[i],dp[j]+1)

            ans=max(ans,dp[i])

        return ans
```
