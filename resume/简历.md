# easy-im 高并发即时通讯系统  
  
**技术栈**：Go / go-zero / GORM / MySQL / MongoDB / Redis / Kafka / gRPC / WebSocket / Docker  
  
**项目简介**：基于 go-zero 微服务框架构建高并发即时通讯（IM）系统，覆盖**账号与好友关系、单聊、群聊、会话列表、聊天记录、已读回执**等核心能力；采用 **WebSocket 长连接 + Kafka 事件驱动异步化**解耦消息主链路，通过 **JWT 鉴权、消息 ACK 可靠性机制与 Redis 缓存**提升系统吞吐与稳定性。  
  
- **微服务架构拆分**：基于 go-zero 将系统拆分为 user（用户）、social（社交）、im（消息：api/rpc/ws 三端）、task/mq（异步任务）四大微服务，服务间通过 **gRPC（zrpc）** 通信，各服务独立部署、可水平扩展。  
  
- **自研 WebSocket 长连接网关**：基于 gorilla/websocket 封装连接管理（user↔conn 双向映射）、方法路由与 **JWT 握手鉴权**；设计 **消息 ACK 机制（OnlyAck / RigorAck）**，通过序号校验 + 超时重发保障消息可靠到达与不丢不重。  
  
- **Kafka 事件驱动异步化**：消息发送走 WS → Kafka → 独立消费者「落库 + 回连推送」两段式处理，将高频收发与低频落库解耦，实现**削峰缓冲与消费失败重放**，显著降低发送接口延迟。  
  
- **消息存储与会话管理**：基于 **MongoDB** 存储聊天记录与会话数据，采用 **位图（Bitmap）** 实现消息已读状态与回执记录；设计会话 ID 生成算法（雪花 ID + 双端排序拼接）保证单聊会话稳定唯一，支持未读数累计与最后消息预览。  
  
- **消息路由与推送**：单聊基于连接映射**点对点精准推送**，群聊基于群成员列表**扩散推送**（含发送者过滤），实现 1:N 场景的高效分发。  
  
- **Redis 缓存与安全加固**：JWT + Redis 维护系统 Token 与登录态，好友请求链路引入**幂等中间件**防重复提交；封装统一缓存读写服务（CacheService），降低 MySQL/底层查询压力。  
  
- **Docker 容器化部署**：为全部服务编写独立 Dockerfile，配套 make 构建脚本与一键部署脚本，实现多服务容器化、可复现的快速部署。
